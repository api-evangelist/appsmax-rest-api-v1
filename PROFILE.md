# AppsMax REST API v1

REST API for the AppsMax SaaS platform, a Russian-language service for launching apps, booking, orders, mini apps, groups, channels, messaging, GigaChat and integrations in MAX and Telegram. The server-to-server API lets integrators read bots, connections, mini apps, scenarios and menus, and work with applications, subscribers and campaigns.

- **AppsMax REST API** — Server-to-server REST API (v1) with Bearer/scope authentication, 17 paths covering bots, connections, mini apps, funnels, interactive menus, applications, campaigns and subscribers. Backed by a public OpenAPI 3.0.3 contract. (`https://telegram.appsmax.ru/api/v1`)
