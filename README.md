# appsmax-rest-api-v1

AppsMax.ru is a Russian-language SaaS platform for small business, communities and integrators — customer requests, online booking, orders, mini apps, groups, channels, messaging, GigaChat and integrations inside MAX and Telegram. Its developer surface is a single server-to-server REST API (v1) with a public OpenAPI 3.0.3 contract, an APIs.json index, an API Onboarding Descriptor and an llms.txt.

- APIs.json: https://appsmax.ru/apis.json
- Documentation: https://appsmax.ru/developers/
- Profile: [PROFILE.md](PROFILE.md)
- Descriptor: [apis.yml](apis.yml)
